Does Analytics Investment Pay Off? Data-Driven Decision-Making in FMCG Marketing: Most FMCG companies are investing heavily in analytics. The harder question is whether that investment translates into better revenue, customer growth, portfolio expansion and leaner marketing teams, or whether the benefits depend on how the data is used. This project evaluates the evidence rather than assuming analytics works.Approach: 30-source evidence synthesis, 50-entry coding framework, four themes, and a Unilever vs PepsiCo vs mid-sized manufacturer comparison with a KPI dashboard.Repository contents: Full dissertation (PDF), source log, thematic coding table, theme development record, codebook, analysis framework, comparative dashboard
